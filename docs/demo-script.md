# Desktop AI 演示视频脚本

**时长**：~2分30秒
**模型**：银狼（主）、Firefly 流萤（切换演示）
**录制工具**：OBS，区域录制 340×360 窗口 + 设置界面
**字幕**：全程中文字幕

---

|------|------|------|

## 录制注意事项

1. **窗口大小**：OBS 区域录制 340×360 宠物窗口，需要时切到设置窗口
2. **BGM**：轻快的 lo-fi / chip tune，音量低于人声
3. **字幕**：用剪映自动识别 + 手动修正
4. **AI 响应时间**：录制时可以加速（2×）或剪掉等待时间
5. **备用对话**：如果 AI 回复不符合预期，准备备用 prompt 重试
6. **隐私**：API Key 区域打码（OBS 滤镜 → 模糊遮罩）
7. **Firefly 版权**：视频简介注明模型作者 @是依七哒
